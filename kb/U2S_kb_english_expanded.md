# High-level product summary

Teppy is a portable internet hotspot that lets users connect multiple personal devices to the internet while traveling. It includes built-in **Sapphire CloudSIM technology** to help the device connect to the strongest signal available in the area. Users activate the device by linking it to a Sapphire account, then purchasing and using a data package through the Sapphire app or dashboard.

Teppy also supports a **physical MicroSIM card** for local SIM use. If a customer inserts a physical SIM card, they can manage the SIM from the device admin page at **192.168.43.1**.

4. Manually enter the APN information for the SIM card

## Expanded support explanation
An APN, or Access Point Name, is the network configuration a carrier uses to connect a device to mobile data service. If a local SIM card is inserted but not connecting, the APN may need to be entered manually.

# Structured troubleshooting decision tree

## Problem: Device does not turn on
Possible causes:
- battery is depleted
- device needs charging
- power button was not held long enough

Recommended actions:
1. Press and hold the power button for 3 seconds.
2. If no LEDs turn on, connect the included charger.
3. Prefer wall charging over a computer USB port.

## Problem: Wi-Fi network appears but there is no internet
Possible causes:
- service is still connecting
- network conditions are weak
- first use in country is taking longer
- service error may be present

Recommended actions:
1. Check whether the Wi-Fi LED is flashing.
2. Wait 1 to 2 minutes for normal connection.
3. If using in a new country for the first time, wait up to 10 minutes.
4. If the signal LED is flashing, treat it as a service error case.

## Problem: Device is frozen or not responding
Recommended actions:
1. Press and hold the power button for 18 seconds.
2. If a full restart is needed and configuration issues persist, use the reset button for 5 seconds to restore factory settings.

## Problem: Local SIM card is inserted but mobile data does not work
Recommended actions:
1. Turn off the device before reinserting the SIM card.
2. Confirm the SIM is a MicroSIM.
3. Log in to 192.168.43.1.
4. Manage and select the SIM card.
5. Go to Settings > APN settings.
6. Manually enter the carrier APN and save.

## Problem: Need to protect account after losing device
Recommended actions:
1. Open the Sapphire app.
2. Use the Unbind option.
3. Contact customer service.

# Glossary

## APN
Access Point Name. A carrier network setting required for some SIM cards to connect to mobile data.

## CloudSIM
Built-in Sapphire connectivity technology that helps the device connect using supported service access without requiring a customer to rely only on a physical SIM.

## IMEI
A device identification number used during device activation.

## LED
Light indicator on the device that communicates power, signal, battery, charging, or system status.

## MicroSIM
The physical SIM size supported by Teppy for local SIM usage.

## SSID
The visible name of the Wi-Fi network.

## Unbind
A function in the Sapphire app that disconnects the device from the user's account to prevent unauthorized use.
