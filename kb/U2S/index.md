# How to use the rental device

## Getting started
The rental device comes pre-configured with a data plan. No app download, no account creation, and no internet connection is needed to set it up.

1. **Turn on the device** — press and hold the power button for 3 seconds
2. **Wait for connection** — the device connects automatically (1-2 minutes, up to 10 minutes in a new country)
3. **Connect your phone/laptop** — join the Wi-Fi network named **Tep_XXXXXX** (name and password are on the device label)
4. **Ready** — the Wi-Fi LED stays on when connected

## Requirements for the device to work
- The device must have an **active data plan** (pre-loaded by TravelWifi)
- The customer must be in an area with **cellular coverage** on supported bands
- The device must be **charged** (or plugged in)

## If the device does not connect
- Check that the Wi-Fi LED is flashing (connecting) — wait 1-2 minutes
- If first time in a country, wait up to 10 minutes
- If signal LED is flashing, there is a service error — escalate
- Confirm the plan is active and covers the customer's destination

# Local SIM troubleshooting

## SIM not working — steps
1. Turn off the device before reinserting the SIM
2. Confirm the SIM is a **MicroSIM**
3. Log in to **192.168.43.1**
4. Manage and select the SIM card
5. If still not working, manually enter the APN:
   - Go to **Settings > APN settings**
   - Enter the carrier APN information
   - Save

## What is APN?
Access Point Name — the network configuration a carrier uses to connect a device to mobile data. If a local SIM is not connecting, the APN may need to be entered manually.

# Connection timing

## Normal connection
Device usually takes **1 to 2 minutes** to connect after powering on.

## First-time use in a new country
May take **up to 10 minutes** the first time the device connects in a new country. This is normal — the device is negotiating with local carriers.

## No connection after 10 minutes
- Confirm the plan is active and covers the destination country
- Check signal LED: if flashing, there is a service error
- Try power cycling: hold power button 5 seconds to turn off, then 3 seconds to turn on
- If still not connecting, escalate

# Troubleshooting decision tree

## Device does not turn on
Possible causes: battery depleted, not charged, button not held long enough.
1. Press and hold the power button for **3 seconds**
2. If no LEDs turn on, connect the charger (wall outlet recommended)
3. Wait for battery LED to flash (charging), then try again

## Wi-Fi network appears but no internet
Possible causes: still connecting, weak signal, first use in country, service error.
1. Check if the Wi-Fi LED is flashing (still connecting — wait)
2. Wait 1-2 minutes for normal connection
3. If first time in country, wait up to 10 minutes
4. If signal LED is flashing, there is a service error — escalate

## Device is frozen or not responding
1. Press and hold the power button for **18 seconds** (force restart)
2. If issues persist, press the reset button for 5 seconds (factory reset — does not affect data plan)

## No signal / poor connectivity
1. Confirm the destination country is covered by the plan
2. Check the signal strength LEDs — more dots = stronger signal
3. Move to an area with better cellular coverage (near a window, higher floor)
4. Power cycle the device
5. If persistent, escalate — may be a carrier issue in that region

## Local SIM not working
1. Turn off device, reinsert the SIM
2. Confirm it is a MicroSIM
3. Log in to **192.168.43.1**
4. Select the SIM card
5. Go to Settings > APN settings, enter carrier APN and save

## Customer reports data used too quickly
1. Advise turning off the device when not actively using internet
2. Explain background data consumption (updates, sync, streaming)
3. Check CDR records for unusual usage patterns
4. If usage seems abnormal, escalate

## Lost or stolen device
1. Unbind the device from the account (customer service action)
2. Log the incident

# Glossary

## APN
Access Point Name. A carrier network setting required for some SIM cards to connect to mobile data.

## CloudSIM
Built-in connectivity technology that connects the device to local carriers without requiring a physical SIM card. The rental data plan uses CloudSIM.

## IMEI
Device identification number. Found on the back of the device and used for device management.

## LED
Light indicator on the device that shows power, signal, battery, charging, or system status.

## MicroSIM
The physical SIM card size supported by this device (only needed if customer wants to use their own local SIM).

## SSID
The visible name of the Wi-Fi network broadcast by the device.

## Unbind
Disconnects the device from the user account. Used when a device is lost or stolen to prevent unauthorized data usage.
